## 業務での取り組み

| 領域 | 内容 | 成果 |
|---|---|---|
| **制作パイプライン** | 店舗向けLP・動画の自動生成（Astro + React + TypeScript / kintone連携 / CMS掲載・業務DBへの書き戻しまで）。動画は HyperFrames（HTML＋GSAPで組んだ映像をMP4に書き出す仕組み）でコードから作り込む方式も導入 | 3名体制だった制作を自動化し、その3名の顧客対応業務への配置転換につなげた。100店舗超で運用中 |
| **大規模データ処理** | 数百万件規模のリストの名寄せ・重複排除・判定をPythonで自動化 | 毎週約8時間かかっていた抽出作業を約1時間に短縮 |
| **営業支援** | カレンダー連携 → 顧客調査 → 提案資料の自動生成 → 業務DBへの書き戻し | 商談準備の手順を標準化 |
| **グループ会社のAI研修・伴走** | グループ会社5社それぞれと週1回、研修と壁打ち | 各社の業務に合わせた環境（CLAUDE.md・Skills 等）の構築まで伴走 |
| **手順の資産化** | 反復する業務手順を Claude Code のスキルとして整備（20本） | 別の担当者・端末でも同じ手順で実行できる状態に |

どれも「動くものを作って終わり」にせず、**他の人が同じ手順で回せる形にして引き渡す**ところまでを1セットにしています。

### Claude Code の実務運用

2台のマシンで Claude Code と Codex を併用しています。

- **CLAUDE.md の3階層運用**（全体共通・業務領域・案件）— 禁止操作と業務データ保護のルールを明文化し、誤操作の予防に活用。CLAUDE.md は強制力のある設定ではないため、削除・上書きなど影響の大きい操作は、承認を求める手順として明記
- **Skills（20本）** — 反復する業務手順をスキル化
- **MCP 連携** — kintone などの業務サービスを接続し、業務フローに組み込み
- **サブエージェント** — 工程ごとに役割を分け、承認が必要な工程だけ人の判断を挟む

## 作品

### 店舗向け 縦動画の自動生成デモ

▶ デモ動画（約1分）：https://youtu.be/IzgLWOrfi3M

メニューを選ぶと、手元の写真・動画素材から、ナレーション付きの縦動画と投稿画像・投稿文をまとめて書き出す仕組みです。構成・テロップ・動きは Claude Code のスキルが組み立て、HyperFrames（HTML＋GSAP → MP4）で書き出し、ナレーションは Gemini TTS で付けています。動画に出てくるのは架空の店舗で、写真・動画は AI で生成した素材です。

`Claude Code` `HyperFrames` `GSAP` `Gemini TTS` `ffmpeg`

### 生成AI活用メディアの運用基盤（個人開発）

記事の企画・執筆・SEO最適化・投稿・分析を、**7つの役割（エージェントのセッション）に分け、ファイル経由で成果物を受け渡す構成**で運用し、記事63本を制作しました。WordPress REST API による投稿の自動化と、Google Search Console API による検索パフォーマンスの自動取得まで組み込んでいます。

`Python` `WordPress REST API` `Google Search Console API` `MCP`
